# Playtest Contract

Run these steps in a real Godot window after navigation, resource, or building changes.

1. Start the game and close the help dialog.
2. Select all three starting workers and order them through a tree line to open ground.
3. Place a building across their route and verify they keep moving around it.
4. Order one worker to gold, wait for pickup and return, and verify the top-left value increases.
5. Exhaust a tree and verify the worker returns its final carried load before switching trees.
6. Build a barracks, select it, produce a sword unit, and verify it appears immediately.
7. Zoom from minimum to maximum and verify selection and right-click targets match the cursor.
8. Check the Debugger after the run: no repeating errors are acceptable.
